# Subdomain Enumerator
This is a tool for finding active subdomains on a target website. Reads sub domain names through a separate text file that can easily be modified or replaced.
USE RESPONSIBLY! Only use the tool on websites you have permission to.

## Instructions
To run the program:
1. CD into wherever you saved the repo files.
2. Run `python3 Subdomain-Finder.py` (Must have Python installed)
3. Enter a valid web address when prompted.
